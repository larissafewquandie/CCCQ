Rebuild it in Prezi

Six steps to your Prezi

  1. Use the house as your canvas. Upload the house picture (labelled version) as the background image of a new Prezi.
  2. One topic per room. Draw a topic frame over each of the 11 parts. Name each one exactly as it appears here, so the words and the picture match.
  3. Set the path top to bottom. Order the path 1 to 11, the same as the numbered badges. Roof first, street last. Same route every time.
  4. Three subtopics inside each room, no more. Memory hook, What happens here, Where it goes next. Three is easy for working memory to hold.
  5. Keep the colours. Give each topic the same colour as its room. Colour becomes a shortcut your brain will use without trying.
  6. Make a blank copy. Duplicate the Prezi and swap in the unlabelled picture. Use it to test yourself: zoom to a room, say what lives there, then check.
Why this works for an ADHD brain

The learning science

Memory palace

Your brain remembers places far better than lists. Putting each task in a room gives it an address.

Picture plus words

Seeing an image and reading a label at the same time stores the idea twice, so there are two ways back to it.

Small chunks

Four floors, never more than five things per floor. That stays inside what working memory can juggle at once.

Hierarchy you can see

Up the house means up the chain. You don't have to remember the structure, you look at it.

Testing beats rereading

Recall mode makes you pull the answer out before you see it. That effort is what makes it stick.

Your brain, outside your head

The board holds the plan so your executive function doesn't have to. Glance at it instead of keeping it all in mind.
